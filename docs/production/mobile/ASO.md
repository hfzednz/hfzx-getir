# App Store Optimization (ASO)

Canonical copy lives under `store/aso/{customer,courier,warehouse}/`.

## Fields

| Field | Guidance |
|-------|----------|
| Application name | **NEXORA** — brand first (Kinetic Clarity) |
| Subtitle | City-speed grocery delivery (localize) |
| Description | Short + full; lead with brand; no keyword stuffing |
| Keywords | Locale-specific; exclude competitor trademarks |
| Screenshots | Phone + tablet; no fake UI; show real product journey |
| Feature graphic | Play only; brand-dominant |
| Preview video | Optional; first 3s brand |
| Localization | TR + EN minimum; extend via global-service locales |
| Privacy labels | Accurate; location/notifications declared |
| Store compliance | No misleading ETA/pricing claims |

## Compliance checklist

- [ ] Privacy policy URL live
- [ ] Account deletion path documented
- [ ] Permissions rationales in-app and store forms
- [ ] Payments use store-compliant flows where required (digital vs physical goods)
