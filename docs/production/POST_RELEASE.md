# Post-Release

## Watch windows

| Window | Focus |
|--------|-------|
| 0–2h | 5xx, canary, payments, crash-free |
| 2–24h | lag, stockouts, ETA breaches, ANR |
| 1–7d | adoption, reviews, revenue, refund rate |

## Mobile

- Firebase Crashlytics + Play Vitals / Xcode Organizer
- ANR / freeze rate vs baseline
- Store review sentiment triage daily first week

## Business KPIs (Grafana)

- Orders / minute, GMV (minor units), authorize success, cancel rate, courier accept latency, NPS/CSAT if wired

## Feature adoption

- LiveOps exposure vs conversion
- Disable underperforming flags without binary rollback when safe
