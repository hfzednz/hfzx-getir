# Super App Features

| Area | Capability |
|------|------------|
| Registry | Upsert modules (mini_app / plugin / widget / extension) |
| Manifests | Signed versioned bundles, shell compatibility, permissions, hooks |
| Lifecycle | Install / update / remove / rollback |
| Store | Browse, rate, featured, priceMinor + currency |
| Permissions | Sandboxed grant list (payments, search, AI, …) |
| Widgets | Home / dashboard / notification / live / AI / recommendation slots |
| Shell | Resolve installed modules for Flutter dynamic load |
| Search | Cross-module key/name/category search |
| AI | Module recommendations via AI port |
| LiveOps | Module enable gate via LiveOps port |
| Monetization | Commission / partner share rules (bps) |
| Admin | Module counts + listings stats |
| Events | PluginInstalled/Removed/Updated, MiniAppLaunched, WidgetAdded, ModuleActivated, PermissionGranted |
