# Open Platform Features

- Developer/partner apps + OAuth client ref (identity port)
- API keys (hashed; secret shown once)
- Public/private/partner API catalog index (points at existing services)
- API version release events + deprecation fields
- Gateway policies export for Envoy (rate/quota/canary/scopes/cache)
- Webhooks: register, HMAC sign, enqueue, retry, DLQ, replay
- SDK package registry; integration connector metadata
- Usage counters; admin stats; outbox `openplatform.events`
