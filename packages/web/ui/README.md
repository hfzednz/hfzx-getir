# @nexora/ui

NEXORA design system for Admin / Super Admin web (dense density).

Token source of truth: `docs/design-system/tokens/nexora.tokens.json`.

```ts
import { Button, DataGrid, PageHeader, KpiCard } from "@nexora/ui";
import "@nexora/ui/styles.css";
```

Dark mode: set `data-theme="dark"` on `<html>` or use `.nx-dark`.
